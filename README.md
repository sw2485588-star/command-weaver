# Command Weaver

generate me html code for a website, similar to https://matrix.shieldescape.com/, that has an autofill command tool / command library, but a template. have a similar theme but more blue than teal, keep dark black to blue gradient same as matrix. have it so that along the top, horizontally, you can input parameters, and then below it the left third of the screen should be filters, so that when you click on one it narrows the commands returned, and when you click it again the filter unapplies. in the right two thirds of the screen below the params should be the command results, with the command in a copy to clipboard - able - box, with a brief description under it, and these commands should be in a scrollable list
